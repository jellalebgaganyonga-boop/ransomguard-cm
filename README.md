# RansomGuard-CM

Anti-ransomware solution designed for healthcare facilities in francophone Sub-Saharan Africa.

## Architecture

- **agent/** — Windows endpoint agent (C# .NET 8)
- **server/** — Management server (Python FastAPI)
- **cloud/** — Cloud backend for updates and threat intelligence (Python FastAPI)
- **dashboard/** — Web dashboard (React + TypeScript)
- **shared/** — Shared protocols and schemas
- **docs/** — Architecture, API, deployment, user documentation
- **scripts/** — Development and deployment scripts
- **tests/** — Integration, E2E, and security tests
